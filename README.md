# Fastware Mobile App

  > Every cable fails. Ours tells you first.

  Smart cable shopping app built with **Expo** (React Native). Runs natively on Android and iOS.

  ## Features

  - Browse smart USB-C cables (FW·001, FW·002, FW·003)
  - Device compatibility checker
  - Warranty lookup (24-month replacement by order number)
  - Cart with local persistence

  ## Stack

  - Expo / React Native
  - Expo Router (file-based routing)
  - React Query
  - AsyncStorage

  ## Run

  ```bash
  pnpm install
  pnpm expo start
  ```
  Scan the QR code with **Expo Go** on your device.
